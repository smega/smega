### Hi, I'm Szabolcs 👋

Senior SRE / DevOps engineer in Bristol with 15+ years of running infrastructure.
For four years I was the only infrastructure person at a healthcare SaaS company,
so I care about things that let a small team run production calmly: sensible costs,
boring deployments and recovery that doesn't need a hero.

**What's here**

- [runguard](https://github.com/smega/runguard): cron/heartbeat job monitoring
  -- know the moment a scheduled job silently stops running. Self-hostable,
  free, open-source CLI agent ([runguard-cli](https://github.com/smega/runguard-cli)).
- [ghost-infra-scanner](https://github.com/smega/ghost-infra-scanner): finds AWS
  resources quietly costing you money (unattached EBS, idle Elastic IPs, idle NAT
  Gateways) and posts to Slack. Read-only, OIDC, no stored credentials.
- [nevnap-json-adatbazis](https://github.com/smega/nevnap-json-adatbazis): Hungarian
  namedays as JSON, the data behind [nevnapok.eu](https://nevnapok.eu).
- [cluster-dashboard](https://github.com/smega/cluster-dashboard): a readonly
  Kubernetes dashboard, live against the home Raspberry Pi k3s cluster this
  profile's demos run on ([cluster.smega.eu](https://cluster.smega.eu)).
- Contributed to [Home Assistant](https://github.com/home-assistant/core/pull/32353):
  extended the rTorrent sensor integration (merged upstream).
